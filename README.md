# Apple-Inc.-Financial-Modeling-Valuation
Built an Excel-based financial modeling and valuation model for Apple Inc. using historical financial statements and market data. Analyzed revenue, profitability, margins, liquidity, leverage and other key financial ratios.
developed FY2026–FY2028 financial forecasts using operating assumptions; and performed a Discounted Cash Flow (DCF) valuation with WACC, terminal growth and sensitivity analysis to estimate intrinsic value per share.
